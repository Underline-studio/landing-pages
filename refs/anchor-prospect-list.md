## Pre-send research checklist (one pass per row)
1. Confirm decision-maker name + current title via LinkedIn (5 min/row).
2. Confirm award amount and program phase via DOE GDO grants page or company press release.
3. Identify a public artifact (press release, conference talk, IRP filing) within last 90 days as recency hook.
4. Drop into Anchor cold-email touch 1 with the named-token first line.

## Source notes
- DOE GRIP awards: energy.gov/gdo/grid-resilience-and-innovation-partnerships-grip-program (Round 2 selections announced Oct 2024).
- NERC CIP-013-3 effective date: relevant for all NERC-registered entities; reporting cycle drives 2026 spend.
- SPARK: DOE program for state energy-planning automation; applicant list partially public via DOE program office.
